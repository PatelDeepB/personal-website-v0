# Changelog

All notable changes to the personal developer portfolio project will be documented in this file.

## [1.1.0] - 2026-09-29

### Changed
- Replaced all artificial neon lighting, glowing shadows, and saturated gradients with a refined editorial dark aesthetic inspired by Linear, Stripe, and Vercel.
- Replaced cartoon/neon avatar with a clean, high-resolution authentic studio photograph of Deep Patel in natural lighting (`assets/images/profile_avatar.jpg`).
- Replaced glowing sci-fi project cards with realistic high-fidelity web application interfaces (`assets/images/project_ai_studio.jpg` and `assets/images/project_dev_connect.jpg`).
- Refactored `styles/variables.css`: Replaced cyan and violet tokens with clean monochrome, titanium accents, neutral zinc borders, and natural shadows.
- Refactored `styles/base.css`: Removed ambient neon blobs; added subtle linear grid pattern and high-contrast focus rings.
- Refactored `styles/navigation.css`: Simplified brand badge to monochrome styling; replaced neon underline with clean white indicator.
- Refactored `styles/hero.css`: Removed neon pulsing animations; converted buttons to high-contrast monochrome design.
- Refactored `styles/projects.css`: Streamlined filter buttons and project cards into clean minimalist surfaces with subtle hover elevation.
- Refactored `styles/skills.css`: Standardized skill chips and category cards with neutral dark styling.
- Refactored `styles/contact.css`: Updated form inputs and toast alert to clean neutral slate theme.
- Refactored `styles/footer.css`: Replaced lingering accent colors with clean monochrome tokens and highlight borders.
- Updated `index.html`: Cleaned up headline classes and meta descriptions.
- Added `.gitignore`: Configured standard ignore rules for operating systems, logs, and editor configs.

## [1.0.0] - 2026-09-29

### Added
- Created `assets/images/` directory with project media assets.
- Created `styles/variables.css`: Design tokens and CSS custom properties.
- Created `styles/base.css`: CSS reset, typography, and accessibility defaults.
- Created `styles/navigation.css`: Responsive navigation bar and mobile drawer.
- Created `styles/hero.css`: Hero section and developer introduction.
- Created `styles/projects.css`: Projects showcase grid and filter controls.
- Created `styles/skills.css`: Categorized skill cards and chips.
- Created `styles/contact.css`: Contact info card, accessible form, and toast alert.
- Created `styles/footer.css`: Semantic footer and repository links.
- Created `scripts/projectsData.js`: Project data records and query utilities.
- Created `scripts/navigationHandler.js`: Accessible mobile navigation and IntersectionObserver tracking.
- Created `scripts/contactFormHandler.js`: Form validation and clipboard copy utility.
- Created `scripts/main.js`: Application bootstrap script.
- Created `index.html`: Semantic HTML5 single-page application.
- Created `README.md`: Project documentation and GitHub publishing guide.
